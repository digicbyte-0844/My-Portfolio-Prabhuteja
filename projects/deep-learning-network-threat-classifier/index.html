Project case study

Deep Learning Network Threat Classifier

A two-stage deep-learning intrusion detection project for identifying network traffic associated with DoS, DDoS, and port scanning activity.

Focusdeep learning network intrusion detection
Project typeWeb application
Case studyArchitecture & workflows

01 / CASE STUDY

Problem context

Network telemetry can contain patterns associated with malicious or abnormal activity. This project explores a two-stage deep-learning approach to classify traffic associated with denial-of-service, distributed denial-of-service, and port scanning.

02 / CASE STUDY

Modeling approach

The project brief describes a two-stage classifier built with Python and TensorFlow/Keras, with scikit-learn supporting the machine-learning workflow. Model performance should be interpreted alongside dataset composition, class balance, and evaluation methodology.

03 / CASE STUDY

Analytics interface

A Streamlit interface presents telemetry analytics, confusion matrices, and threat-severity classifications to make model outputs easier to inspect.

04 / CASE STUDY

Reported result

The project brief reports 94%+ model accuracy. Accuracy alone does not establish production detection quality; precision, recall, F1 score, false-positive rates, and a clearly documented test split should accompany this figure.

Engineering notes

Key considerations

  • Distinguishing different classes of network activity.
  • Evaluating class-specific performance rather than relying on accuracy alone.
  • Making model outputs interpretable through visual telemetry and confusion matrices.
